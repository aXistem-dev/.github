# aXistem brand

The profile page at [github.com/aXistem-dev](https://github.com/aXistem-dev) is `profile/README.md`.
Its images live in `assets/` and are generated by `scripts/build.py`.

## Mark

<img src="assets/logo.svg" width="96" alt="aXistem mark">

An **X** of two graphite bands carrying circuit traces, with a gradient **A** in front.
The cut-outs around the A and between the bands are transparent, so the same mark works
on light and dark backgrounds.

| File | Use |
|---|---|
| `assets/logo.svg`, `assets/logo.png` | The mark on a transparent background |
| `assets/avatar.svg`, `assets/avatar.png` | Organisation avatar (1024 px, dark background) |
| `assets/banner-{dark,light}.svg` | Profile banner |
| `assets/cards/<repo>-{dark,light}.svg` | Project cards on the profile page |

## Colours

| Token | Dark | Light |
|---|---|---|
| Page | `#0d1117` | `#ffffff` |
| Card | `#161b22` | `#f6f8fa` |
| Border | `#30363d` | `#d1d9e0` |
| Text | `#e6edf3` | `#1f2328` |
| Muted | `#9198a1` | `#59636e` |
| Cyan | `#38d6ff` | `#0b93bf` |
| Lime | `#a3ff3f` | `#4f9a0c` |

The accent gradient runs from cyan `#38d6ff` to lime `#a3ff3f`. Graphite bands: `#525b69` → `#2b313a`.

## Type

- **Exo 2** for the wordmark and card titles
- **Inter** for body text

Both are under the SIL Open Font License (`scripts/fonts/`). Text in the SVGs is converted to
outlines, so the images look the same everywhere.

## Rebuild

```bash
uv run --no-project --with fonttools --with uharfbuzz python scripts/build.py
scripts/render.sh   # PNG versions of the logo and avatar
```

To add a project card, add a `Card(...)` to `CARDS` in `scripts/build.py`, rebuild, and add
the card to `profile/README.md`.
